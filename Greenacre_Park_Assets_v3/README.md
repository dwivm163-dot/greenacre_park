# Greenacre Park reactive map assets v3

17 independent draggable objects: 3 tree clusters, 1 upper pergola, 11 seating sets, 1 waterfall, and 1 stream.

- `physical/park_base.png`: simplified, fixed architecture, ground, buildings, entrance pergola and planted borders. No waterfall or stream on this background.
- `physical/waterfall.png`, `physical/stream.png`: separate watercolor-style, complete illustrations on real transparent backgrounds.
- `ambience/waterfall.png`, `ambience/stream.png`: separate reactive abstract sound symbols on real transparent backgrounds.
- Other PNG/SVG layers carried forward from the previous redrawn set.
- All new waterfall and stream elements are additionally provided as SVG sources.
- `manifest.json` gives asset names and approximate initial positions.

NOTE: The fixed base is a simplified newly drawn approximation, not an exact pixel-identical reconstruction of the original photograph-like illustration. Assets can be resized and repositioned in React.
